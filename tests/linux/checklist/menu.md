# Menu checklist

Run as in [README.md](README.md). Fake home, fresh, unless marked REAL. `→`/`←`: right/left on the row.

## Main menu

1. START ............................ MENU: STATUS · PLAY · SETTINGS; END: SETUP · QUIT
2. FIRST RUN ........................ $STATE/stereo.txt CREATED · PROFILE "Steam Frame (built in)"

## Profiles

3. WORLD SCALE → .................... 1.05 · stereo.txt ipd_scale=1.05 · PROFILE "… · changed"
4. SAVE AS PROFILE "test" ........... "Saved as profile "test"." · profiles/test.txt · PROFILE test · DELETE PROFILE "test" ROW
5. PROFILE ← ........................ "Profile "Steam Frame" loaded." · ipd_scale=1
6. SAVE AS PROFILE "Steam Frame" .... REFUSED: "is built in"
7. SAVE AS PROFILE "a/b" ............ REFUSED: "Not a usable name"
8. PROFILE → test, DELETE PROFILE ... "deleted" · test.txt GONE · PROFILE (none) · stereo.txt UNCHANGED

## Leaving

9.  ESC ............................. MENU STAYS (only Quit closes)
10. QUIT ............................ EXITS · TERMINAL RESTORED

## REAL (your home, look only)

11. STATUS .......................... STEAM · X4 BUILD · LAUNCH OPTION FOUND (or the step to fix it)
12. QUIT ............................ NOTHING CHANGED
